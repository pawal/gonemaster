# Gonemaster Testcase Specifications

This directory contains canonical testcase specifications for gonemaster.

Each testcase spec should be based on current implementation behavior and use
`docs/specifications/templates/testcase-spec-template.md`.

If behavior differs from upstream references, the difference must be documented
in the testcase spec.
When a difference looks like a clear upstream spec/code issue, mark it in the
testcase spec as a potential upstream report with evidence.
